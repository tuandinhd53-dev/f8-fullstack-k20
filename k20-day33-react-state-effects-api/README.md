# Day 33 — React State, Effects & API

Bài tập thực hành React về **State, Effect, Props và Fetch API** trong quá trình học F8 Fullstack K20.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- REST API
- Fetch API

## 📚 Exercises

### 1. User Profile Card

- Fetch user từ DummyJSON API
- `useState` + `useEffect`
- Loading & Error handling
- `AbortController`
- Props & Component Composition
- Previous / Next User

### 2. Product Explorer

- Fetch danh sách sản phẩm
- Search products
- Loading & Error handling
- Controlled Input
- Product List / Product Item / Badge
- Discounted price
- Out-of-stock handling
- Currency formatting với `Intl.NumberFormat`

## 🧠 Key Concepts

```text
API → useEffect → State → Props → Components → UI
```

- `useState`
- `useEffect`
- Props
- Controlled Input
- Conditional Rendering
- `map()` & `key`
- Derived Data
- `AbortController`
- REST API
